界面改进版本，核心功能与 v1.0 相同。

## 本次改动

- 新增 **「每次导出都询问保存位置」** 选项：默认一键导出到自动找到的工程目录，
  勾上后每次导出都会弹出对话框让你选位置
- 自动找不到工程目录时，导出前会**弹对话框询问**，不再默默写到别的地方
- 左右两栏的**分隔线现在可以拖动**（之前左侧面板宽度是固定的）
- 状态栏文字过长时**自动换行**，不再被截断
- 构建脚本改为**自动探测** MSVC / Qt / CMake / Ninja 的安装位置，
  不再写死某个人的路径
- 构建脚本控制台改用 UTF-8，中文路径不再显示成乱码

## 下载哪个

| 文件 | 用法 |
|---|---|
| `oledfonttool-1.1-setup.exe` | 双击按向导安装，可自选安装路径，创建开始菜单/桌面快捷方式，可在控制面板卸载 |
| `oledfonttool-1.1-portable.zip` | 解压后双击 `oledfonttool.exe`，免安装 |

**两种都不需要安装 Qt、Visual Studio 或任何运行库**，全部依赖都在包里。

## 功能一览

- 汉字 → 16×16 点阵字库，格式为 **阴码 / 列行式 / 逆向**（SSD1306 常用）
- 实时预览点阵，字体和阈值可调
- **导出前自检**：逐行检查必须正好 35 字节
- 实时显示字库占用的 Flash 体积
- 支持导入已有字库并**合并**（不是替换）
- 中英文自动混排

## 快速上手

1. 运行 `oledfonttool.exe`
2. 左边输入要显示的汉字
3. 点「导出 OLED_CFont.h」
4. 把文件放进 Keil 工程的 `Hardware\` 目录，Rebuild

字库格式：每行 = 3 字节 UTF-8 编码 + 32 字节点阵 = **35 字节**。
